# mikroSnap

the project has been inspired by physical vintage photobooths. 
the website allows you to choose a desired frame and clicks pictures using a self-run timer. 
you can then download the polaroid strip. you cannot download without taking atleast one picture.
you can reload to start over. 
the page is not resize-friendly(yet). i hope to make resize and mobile friendly in the future.

first time using and experimenting with javascript. 
AI has been used to learn, understand and debug the script. the code itself still remains mostly mine.

all the assets are self-made using affinity by canva. 
the logos used on certain frame are not owned by me. credit to the respective owners.
